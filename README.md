# STEP / STL Viewer

Браузерный 3D-просмотрщик в одном HTML-файле. Ничего ставить не нужно: откройте `index.html` в браузере (нужен интернет — библиотеки грузятся с CDN).

## Форматы
- Открытие: STEP/STP, STL, OBJ, FBX, GLB/GLTF (вместе с .bin и текстурами), 3MF, PLY, PCD, XYZ
- Сохранение: STL (вся сцена или сборка)

## Возможности
- Управление: ЛКМ — вращение, ПКМ — перемещение, колесо — зум
- Кубик видов, стрелки поворота, ISO, ортогональная проекция («Чертёж»), каркас
- Оси CAD: XY — плоскость, Z — вверх
- Цвет и прозрачность модели или отдельной детали
- Измерения: расстояние по 2 точкам, радиус по 3 точкам, привязка к вершинам и рёбрам
- Сборка: несколько деталей, перемещение/вращение, совмещение точка-к-точке и грань-к-грани
- Отмена действий (Ctrl+Z), интерфейс RU/EN
